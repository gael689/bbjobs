# BBJobs

**El trabajo que buscás está en Bahía.**

BBJobs es una plataforma de empleo local, verificada e inteligente. Conecta empresas reales de la región (Bahía Blanca y zona de influencia) con los mejores perfiles profesionales locales, garantizando verificaciones manuales y herramientas que agilizan el proceso de selección.

- [Contexto del Proyecto](contexto_bbjobs.md)

## Estructura del Repositorio (Monorepo)

- `/backend`: API construida con FastAPI, SQLAlchemy y PostgreSQL.
- `/frontend`: Webapp construida con Next.js (App Router), TailwindCSS y shadcn/ui.
- `/docs`: Documentación técnica, planeamiento, y CHANGELOG.
- `/infra`: Scripts relacionados a despliegues y bases de datos.
- `/.github`: Workflows de CI/CD para GitHub Actions.
